# Documentacion del Proyecto

Vault de documentacion viva para arquitectura (arc42), decisiones tecnicas (ADRs), reglas de negocio, guias Diataxis y auditorias de calidad.

## Estructura del Vault

- `ONBOARDING.md`: Guia de incorporacion y rutas de lectura por rol.
- `glosario.md`: Glosario dual de lenguaje ubicuo de negocio y terminos tecnicos DDD/arquitectura.
- `TODO.md`: Panel consolidado (Dataview) de tareas y hallazgos pendientes del vault.
- `arquitectura/`: Documentacion arquitectonica bajo el estandar arc42 (capitulos 01 a 11), modelo relacional, reglas de negocio (`reglas/`) y diagramas de secuencia (`diagramas-secuencia/`).
- `adr/`: Registro inmutable de decisiones de arquitectura (ADRs), indexado en el capitulo 09.
- `guia/`: Documentacion estructurada bajo el marco Diataxis (`how-to/`, `referencia/`, `explicacion/`).
- `auditorias/`: Reportes formales de auditoria (`AUDIT-NNN`).
- `_plantillas/`: Plantillas oficiales para creacion de artefactos documentales.
